# 출처와 한계

## 출처
| 내용 | 출처 |
|---|---|
| 호우주의보 60mm, 호우경보 90mm (3시간) | 기상청 호우특보 기준 |
| 50·80·100년 빈도 강수량 | WAMIS 기후변화 > 홍수 > 설계강수량, 서화(10114030), HadGEM3-RA(2) 과거기간(HIST) |
| 범람 범위 | 하천범람지도 50·80·100년 빈도 (인제군) |
| 땅 높이 | 수치지도 1:5000·1:25000 등고선으로 만든 10m DEM |
| 강 수면보다 몇 m 높은지 | 10m DEM과 인북천 선으로 계산한 상대 높이(REM) |
| 대피소 | 주민대피시설 목록 |

## 한계
- 실제 침수를 예측하지 않는다. 공식 범람 자료를 바탕으로 미리 위험을 알려 주는 안내다
- 비가 오는 위치와 상류 상황에 따라 실제와 다를 수 있다
- 뒷산 높은 곳 길은 지형으로 계산한 방향이라 실제 길과 다를 수 있다
- 기상청 특보나 현장 안내가 이 안내와 다르면 그쪽을 따른다

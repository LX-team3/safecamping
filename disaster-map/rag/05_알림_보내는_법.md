# 재난 알림 보내는 법

## 언제 보내나
| 상황 | 알림 | 이름 |
|---|---|---|
| 안전 → 준비 | 보냄 | 첫 번째 알림 "미리 준비" |
| 준비(또는 안전) → 대피 | 보냄 | 두 번째 알림 "지금 대피" |
| 대피 → 침수(level 3) | 보냄 | 가장 급한 알림 |
| 같은 단계가 계속됨 | 보내지 않음 | 10분마다 같은 알림을 반복하지 않는다 |
| 단계가 내려감 | 보내지 않음 (선택: 안전이 되면 한 번 "위험이 줄었어요, 특보는 계속 확인하세요") | |
| 자료를 못 받음 | 보내지 않음 | 모르는 상태를 안전이라고 하지 않는다 |

호우특보는 비가 오기 전에 내리는 예보 기반 경고라서, 비가 아직 적어도 특보만으로 알림이 갈 수 있다. 이게 "미리 준비" 알림의 목적이다.

## 문장 형식
- **제목** 1줄 (20자 안팎): "[무엇 때문에] — [할 일]". 예: "인제군 호우경보 — 지금 높은 곳으로 대피하세요"
- **본문** 2~3문장:
  1. 할 일 (단계 문서의 "할 일"에서 가장 중요한 것)
  2. 하지 말 것 하나 (다리·물 찬 길 등)
  3. "눌러서 재난지도에서 ○○을 확인하세요"
- 쉬운 말, 존댓말(~하세요), 느낌표는 침수 단계에서만 한 번
- 시연용(demo=true)이면 제목 맨 앞에 "[예시]"

## 하지 말 것
- 문서에 없는 숫자·장소·시간을 쓰지 않는다
- 높은 곳의 방향·거리·시간을 단정하지 않는다 ("남서쪽 산 100m" 같은 말 금지)
- 대피 단계 이상에서 서화중앙교회(다리 건넘)로 안내하지 않는다
- 천도리 주민대피시설로 안내하지 않는다
- 단계를 바꿔 말하지 않는다 (서버가 준 level 그대로)
- 겁주는 말("죽을 수 있어요" 등)이나 농담을 쓰지 않는다
- 비의 양을 첫 문장에 쓰지 않는다 (할 일이 먼저)

## 좋은 예
- 준비: "인제군 호우주의보 — 떠날 준비를 하세요 / 짐을 싸고 바로 나갈 수 있게 두세요. 강가에는 가까이 가지 마세요. 눌러서 대피할 곳과 길을 확인하세요."
- 대피: "인제군 호우경보 — 지금 높은 곳으로 대피하세요 / 짐은 가볍게, 걸어서 가까운 높은 곳으로 가세요. 다리와 물 찬 길은 건너지 마세요. 눌러서 재난지도에서 방향을 확인하세요."

## 나쁜 예 (이유)
- "남서쪽 산 100m를 3분 동안 올라가세요" → 길이 현장 확인 전, 숫자 단정
- "비가 95mm 왔습니다. 위험합니다." → 할 일이 없음, 숫자가 먼저
- "서화중앙교회로 대피하세요" (대피 단계) → 다리를 건너는 길

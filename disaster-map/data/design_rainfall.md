# 설계강수량 (재난 대피 3D 지도 침수 단계 기준용)

- 출처: WAMIS 국가수자원관리종합정보시스템 > 기후변화 > 홍수 > 설계강수량 (wamis.go.kr/wkc/wkc_flooddesign_lst.do)
- 확인한 날: 2026-11-18 (한준서, 화면에서 복사. 파일 다운로드 기능 없음)
- 시나리오: 모두 HIST (과거 기간을 기후모델로 재현한 값). 관측 기록으로 계산한 공식 확률강우량(환경부 확률강우량도)은 아님
  - HadGEM3-RA(1): 세종대학교 개발 모형으로 산정 / HadGEM3-RA(2): 연세대학교 개발 모형으로 산정
- **단위: mm/hr (시간당 강도)**. 총 강수량 = 값 × 지속시간
- 기준으로 쓰는 관측소: **서화(10114030)** — 캠핑장(인북천 물빛테마공원 캠핑장)과 같은 서화면

## 2. 침수 단계 기준표 초안 (팀 확인 전)

3시간 또는 24시간 중 하나라도 기준을 넘으면 그 단계로 본다. 짧고 센 비와 하루 종일 오는 큰비를 둘 다 잡기 위해서다.

| 단계 | 조건 | 지도 | 근거 |

| 1 주의 | 3시간 60mm 이상 | 강가 낮은 사이트 강조 (HAND로 정할 예정) | 기상청 호우주의보 |

## 3. 한계

- 기후모델 과거기간(HIST) 모의값이라 관측 기반 공식 확률강우량과는 다를 수 있다
- 하천범람지도가 몇 시간 지속기간으로 계산됐는지 모른다 (하천기본계획 확인 필요) → 3시간·24시간 둘 다 본다
- 관측소 한 곳의 비로 유역 전체(인북천 531㎢)의 비를 대신한다
- 산간이라 관측소마다 값 차이가 크다 (아래 4-2). 그래서 같은 면의 서화 관측소를 쓴다

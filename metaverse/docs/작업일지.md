## 2026-11-18 (수) — 개발환경 확인, 카라반 모양을 현장 사진처럼

- **한 일**
  - 개발환경 확인: Node·패키지·git 상태 점검, 개발 서버 실행 확인 (새로 설치할 것 없음)
  - 카라반 모양 바꾸기: 회색 상자 → 현장 사진과 닮은 모양 (밝은 회색 판넬 몸체, 짙은 큰 창과 문, 에어컨 실외기, 옆 나무 데크와 검은 파고라, 테이블·의자, 빨간 번호판 `F-12`)
  - 번호판 글자는 줄 이름과 순서(F줄 12번)로 자동으로 만들어져요
  - 낮·밤 선택 기능: 시작 화면에 ☀️ 낮 / 🌙 밤 버튼 추가. 밤에는 하늘이 어두워지고 별·달이 뜨며 캐릭터 손전등이 켜져요 (`daynight.js` 새로 만듦)
  - 달리는 자동차: QGIS에 차량 동선 선 레이어(`car_routes`)를 새로 만들고, 그 선을 따라 차가 시작점에서 끝점까지 달리기를 반복하게 함 (`cars.js` 새로 만듦)
  - 차 앞길에 캐릭터가 있으면 차가 멈추고, 비키면 다시 달리게 함 (안전교육 게임이라 "차가 사람을 보고 멈춘다"를 넣기로 직접 결정)
  - 캐릭터가 차를 통과하지 못하게 함 (움직이는 차에 충돌 상자를 붙여 매 프레임 옮김)
  - 내보내기 자동화: 레이어를 하나씩 손으로 내보내던 것을 파이썬 스크립트(`gis/export_geojson.py`, PyQGIS) 하나로 한 번에 내보내게 함. 반복 작업과 설정 실수를 줄이려고 직접 제안
  - 가로등: QGIS `facilities` 레이어에 가로등 점 4개를 직접 찍고 스크립트로 내보냄 → 게임에서 가로등이 서고 밤 버전에서 불이 켜지게 함 (`lamps.js` 새로 만듦)
  - 침수 미션 검토 후 보류: 팀원의 침수 자료(상대높이 `rem.tif`)를 확인해 보니 캠핑장 안 높이 차이가 자료 오차와 비슷했음. 강물이 불어나는 기능은 만들지 않기로 직접 결정하고, 미리 만들어 둔 관련 코드(`river.js`의 `setFlood`)를 지움
- **확인**: 브라우저에서 카라반 줄까지 걸어가 모양 확인, 밤 화면(별, 손전등) 확인, 차가 도로를 따라 움직이는 것 확인, 오류 없음
- **직접 한 것(자동차)**: QGIS에서 `car_routes` 레이어와 필드(name, speed, count)를 만들고 동선을 직접 그려서 내보냄. 순환 대신 편도 선으로 그리기로 결정
- **직접 한 것**: 카라반 현장 사진 2장을 찾아 참고 자료로 제공, 실제 모습에 맞추기로 결정. 낮 버전과 밤 버전을 고를 수 있게 하자는 아이디어 제안
